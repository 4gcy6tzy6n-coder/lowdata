# quality_noise

Quality-conditioned label-noise detectability and reliability-aware soft
governance. CIFAR-10 / CIFAR-100 / CIFAR-10N / CIFAR-100N, ResNet-18.

## What this repository contains

The **framework only**: the training and evaluation pipeline, the analysis
modules, and the configuration files. No result tables, no figure data, no paper
drafts. Everything under `results/` is regenerated by running the scripts.

```
configs/                 dataset, noise, model and experiment YAML
src/quality_noise/
  data/                  TrainingView / EvaluationView, noise engine, registry
  models/                ResNet-18, feature extraction, pretrained encoders
  traces/                per-sample x per-epoch recorder, training dynamics
  evidence/              loss, forgetting and neighborhood-conflict signals
  quality/               KNN agreement, prototype margin, stability, density
  detectability/         global / matched / quality-stratified AUROC, bootstrap
  governance/            Beta mixture, posterior, soft and hard-exclusion weights
  reliability/           reliability estimator and calibration
  baselines/             CE, small-loss, Co-teaching(+), JoCoR, ELR, DivideMix
  trainers/              standard and weighted trainers
scripts/                 01..13 numbered pipeline + cross-detector + reporting
revision/                Major Revision analysis (see below)
tests/                   unit tests, including the no-leakage guard
```

## The iron rule

**Clean labels and the noise mask are evaluation-only.** They never enter
training, threshold selection, prototype construction or model selection:

- `TrainingView` physically holds only `(x, y_observed, sample_id)`.
- `EvaluationView` holds `clean_labels` and `mask`, and is used only by
  evaluation code.
- `estimate_noise_posterior(E, Q)` has no mask argument.
- `tests/test_no_leakage.py` greps the source for eval-only references outside
  an allowlist.

## Pipeline

```bash
python scripts/01_prepare_data.py   --exp configs/experiments/gate_a.yaml
python scripts/02_collect_traces.py --exp ...   # train ResNet-18, record traces
python scripts/03_compute_quality.py --exp ...  # Q1/Q2/Q3 per sample
python scripts/04_detectability.py  --exp ...   # global / matched / stratified AUROC
python scripts/05_fit_estimator.py  --exp ...   # Beta mixture -> posterior
python scripts/06_train_weighted.py --exp ...   # soft / hard-exclusion governance
python scripts/07_run_baselines.py  --exp ...   # comparison methods
python scripts/11_cross_detector.py             # 6 detectors x N settings matrix
```

Every run is written under `results/` keyed by a config hash, so variants coexist
instead of overwriting each other.

## Major Revision analysis (`revision/`)

The revision asks whether the global-to-quality-matched detectability gap
(`delta_Q = AUC_global - AUC_matched`) is a property of the detectors or of the
quality covariate used to match.

| module | purpose |
|---|---|
| `revq/dinov2.py` | frozen DINOv2 ViT-S/14, implemented against the public checkpoint (no `timm` dependency) |
| `revq/independent_q.py` | class-agnostic density quality: K neighbours in a frozen embedding, no labels read |
| `revq/matching.py` | quality matching: without/with replacement, class-conditioned, common-support trimmed; caliper in SD units |
| `revq/bootstrap.py` | paired bootstrap over samples (one draw drives both statistics) |
| `revq/confident_learning.py` | Confident Learning scores from 5-fold out-of-fold probabilities |
| `revq/prepare.py` | per-run assembly of detector scores and quality covariates, cached |
| `run_p0_independent_q.py` | main grid: per-cell `AUC_global`, `AUC_QC`, `delta_Q`, paired CIs |
| `run_p0b_reversal_audit.py` | matching-rule and common-support audit of the headline setting |
| `run_new1_contamination_sweep.py` | controlled contamination: blend a label-free covariate with a noise-informative one |
| `run_new3_toy_model.py` | synthetic Gaussian model with a closed-form derivation of the artifact |
| `standalone/exact_bootstrap_c100s20.py` | self-contained exact-estimator bootstrap for the CI-bearing cells |

### Headline result

CIFAR-100 symmetric-20%, ten seeds, identical matching rule — only the
conditioning covariate changes:

| covariate | label-free | AUC_global | AUC_QC | delta_Q |
|---|---|---|---|---|
| KNN agreement (label-dependent) | no | 0.696 | **0.390** | **+0.306** |
| prototype margin (label-dependent) | no | 0.696 | 0.465 | +0.231 |
| native density (noisy-trained encoder) | encoder only | 0.696 | 0.623 | +0.074 |
| **DINOv2 density** | **yes** | 0.696 | **0.684** | **+0.013** |
| random (control) | yes | 0.696 | 0.695 | +0.001 |

The gap tracks how much information the covariate itself carries about the noise
label, so the dramatic reversal is a property of a label-dependent, post-treatment
covariate rather than of the detectors.

## Running the standalone bootstrap

`revision/standalone/` is self-contained (numpy, pandas, scipy only) and needs its
data payloads, which are not tracked. See `revision/standalone/README.md` for the
payload layout, the estimator semantics, and the measured cost.

## Environment

Python 3.12, PyTorch 2.x, torchvision, scikit-learn, scipy, pandas, pyarrow.
Remote entry points read connection details from environment variables
(`QN_SSH_HOST`, `QN_SSH_PORT`, `QN_SSH_PASSWORD`); no credentials are stored in
the repository.
